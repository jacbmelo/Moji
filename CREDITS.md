# Credits

## Original application

Moji Plus is a derivative of **Moji**.

- **Application:** Moji, a lightweight, clean desktop app for opening, reading, editing, and exporting Markdown files
- **Author:** Alex Ishida (<https://github.com/alexishida>)
- **Repository:** <https://github.com/alexishida/Moji>
- **License:** MIT, Copyright (c) 2026 Alex Ishida

Almost all of the application's code, design, translations, and documentation comes from the original project. Moji Plus keeps merging its changes (see [.ai-framework/FORK.md](.ai-framework/FORK.md)); the version it is based on is recorded in `package.json` (`upstreamVersion`) and shown in the app under **About › Based on**.

- **Repository:** <https://github.com/jacbmelo/Moji>

## Third-party software

Moji and Moji Plus are built on open-source libraries listed in `package.json`, including Electron, React, CodeMirror, markdown-it, KaTeX, highlight.js, Mermaid, DOMPurify, and i18next, each under its own license.
